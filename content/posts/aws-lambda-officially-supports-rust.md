Starting today, AWS Lambda functions officially support Rust!

[Release blog](https://aws.amazon.com/blogs/compute/building-serverless-applications-with-rust-on-aws-lambda/)

You can install the supporting runtime via [crates.io](https://crates.io/crates/lambda_runtime).

I am a maintainer of the Rust lambda runtime. It's exciting to see what started as a scrappy, community-driven project reach official status. This comes with SLAs and roadmap support that will give developers confidence to build in Rust on Lambda.

Excited to see what new ideas [Astraea Quinn S.](https://www.linkedin.com/in/astraeaqs/) and the Lambda team bring to the open source project!

And, credit to [David Calavera](https://www.linkedin.com/in/david-calavera/) for founding the project, and thank you to champions like [Luciano Mammino](https://www.linkedin.com/in/lucianomammino/) and [James Eastham](https://www.linkedin.com/in/james-eastham/) for helping the runtime achieve industry adoption.

[Runtime 1.0 release notes](https://github.com/aws/aws-lambda-rust-runtime/releases/tag/v1.0)
